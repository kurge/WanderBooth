# ADR 0016: Save reusable placeholder alignments in a staff-managed Template Gallery

**Status:** Accepted

**Date:** 2026-10-02

## Context

Imported transparent artwork and the direct composition editor can fit nearly any event design, but repeating the same alignment after every capture is too slow for a busy booth. The intended workflow is closer to preparing a Canva template: staff define the photo openings before the event, save the setup, then let each session replace the numbered samples with real captures.

Raw artwork and a session-ready template are different things. The same transparent PNG may be reused for more than one alignment or product configuration, while deleting one template should not unexpectedly destroy that source artwork.

## Decision

- Add a staff-only Template Gallery that is available while the booth is idle.
- A saved template records its name, product, layout, imported-artwork reference, artwork transform, per-photo holder transforms, per-photo crop transforms, rotations, and lock state.
- Template setup uses numbered placeholder images instead of requiring real captures. The same direct canvas moves, resizes, rotates, crops, locks, and resets those objects.
- **Save changes** updates the gallery item being edited. **Save as new** duplicates the complete setup under a new identifier and leaves the original intact.
- Approved templates appear before the manual product/layout/frame controls during session selection. Selecting one restores the full saved setup and the layout's required capture count.
- Real captures fill placeholder numbers in capture order. The final review editor remains available for staff-only adjustments that affect only the current session.
- During review, only templates made for the already captured layout may be applied, preventing a saved choice from silently changing the required photo count.
- Staff may delete a saved template without deleting its imported artwork. Artwork referenced by any saved template cannot be deleted until those templates are removed.
- Resetting a session preserves both uploaded artwork and the saved Template Gallery.
- Schema version 10 adds persisted `savedTemplates`, `selectedTemplateId`, and the transient `templateEditor` state.

## Consequences

- Common event designs can be prepared and checked before customers arrive, reducing service time and alignment mistakes.
- One upload can support multiple named template variants without duplicating its private artwork file.
- Template setup is still local to the current Host. Cloud template synchronization and a remote dashboard remain later work.
- All saved templates are currently approved when staff save them. A future owner area may add draft, enabled, disabled, and approval states.
- The customer sees only approved gallery choices. Creation, editing, duplication, deletion, and raw-file import remain staff actions enforced by the Host.

## Revisit when

- undo/redo, multi-select, or alignment guides are added to the editor;
- templates need event folders, search, thumbnails generated by the Host, or explicit draft/disabled status;
- the owner dashboard synchronizes templates between booth computers; or
- template export/import packages are needed for backup or migration.

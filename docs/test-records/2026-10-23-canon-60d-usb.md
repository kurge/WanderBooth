# Canon EOS 60D USB implementation and first physical test

Date: 2026-10-23 · Version: 0.17.0 · Label: Experimental

## Software validation

- Full formatting/lint checks, all 72 unit tests and Host/web/cloud production builds passed.
- Controller tests cover retention flags, exact Canon model and USB-port targeting, wrong/multiple cameras, missing dependency, unsupported Windows, preview/still ordering, invalid JPEG cleanup, preview failure, bounded USB-claim recovery, non-retry of shutter failures and concurrent-command rejection.
- JPEG parsing handles fragmented frames and embedded-thumbnail end markers, with a fixed buffer bound.
- An isolated Host used a synthetic gPhoto-compatible child process. Verified readiness enforcement before a test shot, live JPEG relay, setup rejection during a session, three automatic captures, a retake, event storage, branded individual images, strip, print sheet, slideshow and local QR metadata. No cloud configuration or upload was used.
- Visually checked operator selection, readiness, live preview and test image. Synthetic media was used throughout this UI check.

## Physical observations

- Exact model detected: Canon EOS 60D. No serial number or USB identifier is included in this public record.
- Mac's installed external dependency: gPhoto2 2.5.32; libgphoto2 2.5.34.
- Sandboxed USB enumeration returned no camera; a direct approved USB check detected it. This was a tool-access limitation, not evidence of a faulty cable.
- Initial preview could not claim USB. The active macOS `ptpcamerad` helper ignored graceful termination. Restarting that helper allowed the camera to connect.
- Real live view passed: the new controller decoded and relayed 46 frames by the time the test requested its first still. Test images were not uploaded or committed.
- The still request did not complete successfully. Subsequently, a camera settings read reported USB I/O busy. The user was asked to check power, still-photo mode, writable SD card, JPEG quality and disabled auto power off, and to power-cycle/reconnect before continuing.
- Physical full-resolution photo download, camera-copy verification and post-capture preview recovery remain unverified. Do not infer that synthetic success establishes these results.
